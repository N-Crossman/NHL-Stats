# 🏒 Pucklytics

A modern NHL statistics dashboard built with Next.js, React, TypeScript, and Tailwind CSS. Pucklytics provides real-time game updates, comprehensive player statistics, team rosters, and league standings with an intuitive, mobile-first design.

## Overview

Pucklytics is a comprehensive NHL statistics platform that delivers real-time game data and detailed player analytics. Built with modern web technologies and powered by the NHL API, the application provides hockey fans with instant access to live scores, player performance metrics, team rosters, and league standings.

The platform features a mobile-first responsive design, ensuring a seamless experience across all devices while delivering game updates and extensive statistical analysis.

**Live Site:** [Pucklytics](https://nhl-stats-six.vercel.app/)

## Features

### Live Game Center

- **Daily Scoreboard** - View all games scheduled for the day with live score updates
- **Real-Time Updates** - Automatic refresh of game scores and statistics during live games
- **Game Status** - See scheduled, live, and final game states at a glance

### Player Statistics

- **Comprehensive Stats** - Access detailed player statistics including goals, assists, and points
- **Career Statistics** - View complete career stats for any NHL player
- **Advanced Filtering** - Sort player stats by:
  - Goals
  - Assists
  - Points
- **Search Functionality** - Quickly find any player in the league

### Goalie Statistics

- **Goaltender Metrics** - Specialized stats for goalies
- **Filter by Performance** - Sort by:
  - Goals Against Average (GAA)
  - Save Percentage (SV%)
  - Shutouts

### Team Information

- **Team Rosters** - Complete roster listings for all NHL teams
- **League Standings** - Current league standings that update dynamically
- **Team Performance** - Win-loss-OT loss records and points

### User Experience

- **Mobile-First Design** - Optimized for smartphones and tablets
- **Responsive Layout** - Seamless experience across all screen sizes
- **Intuitive Navigation** - Easy access to all stats and features
- **Fast Load Times** - Optimized performance with Next.js

## Deployment

This application is deployed on Vercel and automatically deploys on every push to the main branch.

**Live Application:** [Pucklytics](https://nhl-stats-six.vercel.app/)

## API

This application uses the **NHL API** to fetch real-time game data, player statistics, team information, and league standings.

**API Endpoints Used:**

- Live game scores and schedules
- Player statistics and career data
- Team rosters and standings
- Goaltender statistics

**Note:** No API key required - the NHL API is publicly accessible.
